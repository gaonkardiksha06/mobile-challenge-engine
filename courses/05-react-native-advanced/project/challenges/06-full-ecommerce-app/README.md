# Challenge: Full E-Commerce App (Capstone)

**Course:** Advanced React Native

## Goal

Complete all tasks for **Full E-Commerce App (Capstone)** in the course project. Work on this challenge only until you pass review (≥ 80%).

## Concepts

- Auth
- Redux cart
- Payments
- Maps
- Firebase
- AsyncStorage

## Tasks

1. Authentication flow
2. Redux cart with persistent storage
3. Stripe checkout
4. Maps and push notifications
5. Firebase image upload and product API

## Technical Requirements

- Implement features in the files listed in `metadata.json` (`filesToCheck`).
- Use TypeScript/JavaScript patterns appropriate for React Native / Expo.
- No `console.log` in production paths; pass ESLint where configured.
- Add `testID` props on key interactive elements for automated tests (e.g. `testID="follow-button"`).

## Verify

```bash
cd courses/05-react-native-advanced/project
npm run review -- --challenge=06-full-ecommerce-app
```

Pass threshold: **≥ 80%**.
